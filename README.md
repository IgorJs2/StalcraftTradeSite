🤝 Stalcraft Trade

Stalcraft Trade is your go‑to marketplace for effortless, secure trading within the Stalcraft community.

    📋 Order Book – Browse active buy and sell orders with intuitive sorting and filtering
    🤝 Discord Integration – Seamless communication: create dedicated Discord channels for each deal via our built‑in bot
    stalcraft.trade
    🔔 Real‑Time Auction – Stay on top of in‑game auctions: live updates pulled directly from the official API
    📊 Price Analytics – Leverage data‑driven insights to track trends and make smart trades

🧑‍💼 My Role

As one of two co-owners and lead developers, I was responsible for designing the architecture, leading backend development, and managing deployment infrastructure.

🏗️ System Architecture & Server-Side Development

    Designed a modular and scalable backend with Nest.js.
    Developed all services such as orders, real time auction, discord integrations, authorization, notification system.

⚙️ Infrastructure & DevOps

    Created a full Docker-based deployment pipeline using:
    
        Docker Compose for environment orchestration.
        GitHub Actions for CI/CD automation.
        Environments deployed to Ubuntu VPS instances with secure SSL and NGINX setup.

🛠️ How It Works

    Browse or Post Orders – Easily list your items or players can request purchases
